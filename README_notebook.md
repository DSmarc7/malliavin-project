# Notebook du projet Malliavin

## Fichiers
- `Malliavin_Project_Notebook.ipynb` : notebook principal
- `requirements.txt` : dépendances minimales

## Exécution locale
1. Installer les dépendances :
   ```bash
   pip install -r requirements.txt
   ```
2. Ouvrir le notebook dans Jupyter ou VS Code.
3. Exécuter toutes les cellules dans l'ordre.

## Exécution via GitHub / Colab
- GitHub affiche les notebooks `.ipynb` en HTML statique.
- Pour exécuter le notebook dans le cloud, on peut l'ouvrir dans Google Colab depuis un dépôt GitHub.
